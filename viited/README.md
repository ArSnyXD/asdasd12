# Alles jäetud võrdlusmaterjal

Need pildid olid failis [ULESANDED.md](../ULESANDED.md) kirjeldatud paranduste eeskujud ja veanäited. Rühmad 1–6 on tehtud versioonis 0.6.0 ja rühmad 7–9 versioonis 0.7.0 (vt [SEIS.md](../SEIS.md)); pildid on alles kasutaja ülevaatuseks ja hilisemaks võrdluseks. Need ei ole mängu tekstuurid ega tõendid uute paranduste valmimise kohta; tõendid luuakse uuesti käsuga `node tooriistad/vaatekontroll.mjs`. Pildifailid on algsel kujul; tõlgitud on nimed ja selgitused.
